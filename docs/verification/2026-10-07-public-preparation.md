# Проверка переносимости конфигурации

Gitleaks проверил всю доступную историю Git (`--all`) и текущие tracked/new
файлы, с полной редакцией возможных значений: найденных секретов — 0.
`data/`, исходники пользовательских документов, речь, `.env.local` и
credentials не входят в Git/Docker context. Исторические бинарные файлы —
публичные иконки, социальная карточка и демонстрационное видео сайта.
Результат сканера не является гарантией отсутствия любых возможных приватных данных.

В `0.2.0` личные defaults убраны из runtime/CLI: endpoints, verified subject,
имена pass entries, registry и CDN задаются явно. Личный источник отключён
без конфигурации, scopes пусты. PostgreSQL policy использует transaction-local
subject и проверяет сохранённую verified identity; local-аккаунт с совпадающим
именем не получает прав. Публичная HTML-страница получает только allowlist
полей и экранирует значения.

Проверки: TypeScript, shell syntax, diff whitespace; 7 тестов конфигурации и
релизов (59 assertions), 17 интеграционных/модульных тестов (115 assertions)
на отдельной временной PostgreSQL/pgvector базе и непривилегированной роли.
Миграции применены дважды. База/роль удалены. Проверены настраиваемый
Corp-владелец, сохранение его прав при установке пароля, изоляция документов
и WebSocket, отсутствие частичного индекса и восстановление очереди.

README содержит существующий SVG-логотип, описание сервиса и настройку своего
окружения. GitHub About содержит описание, ссылку на сайт и темы проекта.
