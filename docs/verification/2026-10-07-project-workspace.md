# Отдельные экраны проектов, настроек и выступления

Запрос: отделить список и переключение проектов, подготовку материалов и само выступление.

Результат: `/app/` открывает карточки проектов с количеством документов и готовностью. Создание — отдельный диалог, после него настройки проекта. Настройки включают название, загрузку кнопкой/drag-and-drop, статусы и повтор обработки, личный источник только для владельца. Выступление занимает отдельный экран; дополнительные действия, расшифровка, подсказки клавиш и технические статусы находятся в меню. Переходы поддерживают history и reload. Свой микрофон выключается при уходе с выступления.

Текущая сессия сохраняется явно, включая пустую новую колоду. В проектах восстановление не ограничено прежними 12 часами. При изменении источников открытые комнаты пересоздаются с сохранённой колодой; настройку нельзя сохранить во время записи другой вкладки. API обновления проверяет владельца и возможность личного источника, PostgreSQL RLS остаётся включён.

Проверены tenant boundary, PATCH чужого проекта, отказ личного источника локальному аккаунту, пересоздание WebSocket комнаты, восстановление сессии и источников, восстановление после долгого перерыва и пустая новая сессия. Тестовая БД/роль удалены.

Создание, изменение названия, upload TXT, три экрана, смена проекта, back/reload, расшифровка, горячие клавиши, скрытие личного источника для локального аккаунта. JavaScript errors отсутствуют, горизонтального переполнения нет; screenshots просмотрены.
