# Живые слайды

Приложение слушает микрофон, распознаёт речь и создаёт слайды по ходу беседы.
Поиск в OpenViking даёт дополнительный контекст для слайдов и прогнозов.

Для запуска нужны Bun, OpenAI-совместимый LLM endpoint и выбранный движок
распознавания: ElevenLabs или локальный whisper.cpp.

```sh
bun install
bin/start
```

Адреса, модели и источники задаются переменными окружения из `.env.example`.
Настройте собственные сервисы; встроенные адреса служат только примерами.
Секреты передаются через env или явно выбранные записи `pass` и не хранятся
в Git. Материалы сессий остаются в исключённом из Git каталоге `data/`.

Описание принятых решений — [docs/adr/](docs/adr/).
